# Summer-Research-Project-2026
All code for graphs, plots and correlations form my summer research project on axial GaAs/MnAs heterostructure nanowires

To use the code you need to download the data from the excel pages as CSV UTF-8 files and have them in the same folder as the rest of the code. 
After downloading the CSV file you have to choose if you want the calculated values or the measured for the ones with large moire and remove the other one from the file.

Sometimes code like: df = df[df["Bottom"] == "Yes"] or df = df[df["C"] >= 225] appears in the code. This is just a way of altering which data is being used.
